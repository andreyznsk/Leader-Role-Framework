# Architecture Decision Records

ADR — фиксируем архитектурные решения: что решили, почему, какие были альтернативы.

## Список решений

| # | Название | Дата | Статус |
|---|----------|------|--------|
| ADR-001 | [Шаблон] | YYYY-MM-DD | Proposed |

## Как создать новый ADR

```
Используй суб-агент doc-writer:
"Создай ADR для решения: [описание решения].
 Контекст: [почему встал вопрос].
 Альтернативы: [что рассматривали]."
```

Или скопируй шаблон `_template.md` → `ADR-NNN-название.md`
