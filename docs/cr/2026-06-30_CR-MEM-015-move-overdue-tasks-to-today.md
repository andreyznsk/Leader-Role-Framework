# 2026-06-30_CR-MEM-015: Move overdue tasks to today from Today UI

**Дата:** 2026-06-30  
**Статус:** Draft  
**Сервис:** MEM / JavaMemoryService  
**Тип:** Enhancement / UI  
**Branch:** feature/mailAg-001

## Проблема / Мотивация

На странице `/ui/today` пользователь видит задачи текущего дня и управляет ежедневным планом.

Сейчас просроченные задачи с дедлайном раньше сегодняшней даты остаются на старых датах. Пользователю приходится вручную переносить каждую такую задачу на сегодня, чтобы восстановить актуальный план дня.

Нужна быстрая batch-операция: перенести все просроченные незавершённые задачи на сегодня одной кнопкой.

## Решение

Добавить на правую панель страницы `/ui/today` кнопку под кнопкой `Добавить новую задачу`:

```text
Перенести просроченные на сегодня
```

Поведение кнопки:

1. Находит все задачи, у которых deadline/dueDate меньше сегодняшней даты.
2. Переносит такие задачи на сегодняшнюю дату.
3. Переносит только активные незавершённые задачи.
4. Не трогает задачи в статусах `DONE`, `ARCHIVED` и legacy `DELETED`.
5. После выполнения обновляет Today UI, чтобы перенесённые задачи сразу появились в списке текущих задач.
6. Показывает пользователю результат операции: сколько задач перенесено.

## Рекомендуемая бизнес-логика

Критерии выбора задач:

```text
dueDate < today
AND status IN (PENDING, TODO, IN_PROGRESS, BLOCKED if supported)
AND status NOT IN (DONE, ARCHIVED, DELETED)
```

Целевое изменение:

```text
task.date = today
task.dueDate = today
```

Если в текущей модели есть различие между `date` и `dueDate`, рекомендуется:

- `date` — день отображения в Today UI;
- `dueDate` — дедлайн задачи;
- для этой операции обновлять оба поля на today, чтобы задача больше не считалась просроченной и была видна в сегодняшнем плане.

## Изменения в API

Добавить endpoint в `JavaMemoryService`:

```http
POST /api/tasks/move-overdue-to-today
```

Ответ:

```json
{
  "moved": 3,
  "today": "2026-06-30"
}
```

Ошибки:

- `200 OK` — операция выполнена, даже если `moved = 0`;
- `500` — внутренняя ошибка batch update.

## Изменения в схеме БД

Не требуются.

Операция должна использовать существующую таблицу задач и существующие поля даты/дедлайна.

## Зависимости

- `JavaMemoryService`
- `/ui/today`
- существующие поля задачи: `date`, `dueDate` / deadline
- существующие статусы задач: `PENDING`, `TODO`, `IN_PROGRESS`, `DONE`, `ARCHIVED`, legacy `DELETED`
- существующий механизм move task, если он уже реализован

## UX требования

1. Кнопка размещается в правой панели под кнопкой `Добавить новую задачу`.
2. Текст кнопки: `Перенести просроченные на сегодня`.
3. Перед выполнением желательно показывать confirm dialog:

```text
Перенести все просроченные незавершённые задачи на сегодня?
```

4. После успешного выполнения показать toast/alert:

```text
Перенесено задач: N
```

5. Если задач для переноса нет, показать:

```text
Просроченных задач нет
```

6. После операции страница `/ui/today` должна обновить список задач.

## Как тестировать

### Manual

1. Запустить инфраструктуру и `JavaMemoryService`:

```bash
docker compose up -d
SPRING_PROFILES_ACTIVE=local java -jar JavaMemoryService/target/memory-service.jar
```

2. Создать тестовые задачи:

- `TODO` с `dueDate = today - 1 day`;
- `IN_PROGRESS` с `dueDate = today - 2 days`;
- `DONE` с `dueDate = today - 3 days`;
- `ARCHIVED` или legacy `DELETED` с `dueDate = today - 4 days`;
- `TODO` с `dueDate = today`.

3. Открыть:

```text
http://localhost:8082/ui/today
```

4. Нажать кнопку:

```text
Перенести просроченные на сегодня
```

5. Проверить:

- перенесены только `TODO` и `IN_PROGRESS` просроченные задачи;
- `DONE`, `ARCHIVED`, `DELETED` не изменились;
- задачи появились в Today;
- UI показал корректное количество перенесённых задач.

### E2E

Добавить сценарий:

```text
JavaMemoryService/test_e2e/15_move_overdue_tasks_to_today.md
```

Сценарий должен:

1. Создать несколько задач с прошедшими датами и разными статусами.
2. Вызвать `POST /api/tasks/move-overdue-to-today`.
3. Проверить `moved` в ответе.
4. Проверить через `GET /api/tasks?date=<today>`, что активные просроченные задачи появились сегодня.
5. Проверить, что `DONE`, `ARCHIVED`, `DELETED` не были перенесены.
6. Проверить smoke `/ui/today`, что кнопка присутствует в HTML.
