# K8s Explorer Skill

Скилл работает в двух режимах:

- **`explore <namespace>`** — исследует один неймспейс, сохраняет `<namespace>.md`
- **`summary <папка>`** — читает все `.md` файлы из папки, строит `report.html`

Прочитай references/explore.md и references/summary.md для деталей каждого режима.

---

## Определение режима

Если пользователь говорит:
- "исследуй ns-payments" / "посмотри неймспейс X" / "что в X?" → режим **explore**
- "собери отчёт" / "summary по папке" / "объедини все MD" → режим **summary**
- "исследуй все неймспейсы" → режим **explore** последовательно для каждого, затем предложи **summary**

Если неймспейс не указан — спроси: "Какой неймспейс исследовать? Или запустить по всем?"

---

## Быстрый старт

### Explore одного неймспейса

1. Прочитай `references/explore.md`
2. Подключись через MCP и выполни все шаги сбора данных
3. Сохрани результат: `<namespace>.md` в рабочую папку

### Summary по всем неймспейсам

1. Прочитай `references/summary.md`
2. Прочитай все `.md` файлы из указанной папки
3. Сгенерируй `report.html` и сохрани рядом

---

## Важные принципы

- **Не паникуй при ошибках MCP** — если команда вернула ошибку, запиши её в MD и продолжай
- **Фиксируй всё** — даже если данных мало, лучше пустая секция чем пропущенная
- **Не интерпретируй** на этапе explore — просто собирай факты; анализ в summary
- **Прогресс вслух** — сообщай пользователю что сейчас делаешь ("Собираю поды...", "Анализирую события...")
