Главная идея
AI является сменным компонентом системы. Для перехода на нового provider достаточно заменить реализацию клиента.
Prompt Contract
Один файл AGENT.md и симлинки для Claude, Codex и GigaCode.
Java API
Mail Agent, Memory Service и RAG Service работают только через AgentClient.
Runtime Swap
Подключаем Claude, Codex, GigaChat, Ollama или Mock без переписывания сервисов.
Меняется AI Runtime — архитектура LeaderOS остаётся неизменной.
