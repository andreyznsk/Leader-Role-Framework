# CR-MEM-004: Кнопка перехода на презентацию LeaderOS в навигации

**Дата:** 2026-06-13
**Статус:** Draft
**Сервис:** MEM — JavaMemoryService
**Зависимости:** presentation.html должен быть размещён в `src/main/resources/static/`

---

## Проблема / Мотивация

Презентация LeaderOS (`leaderOS-pitch-v5.html`) создана для питча тех лиду и руководству трайба.
Чтобы запускать её прямо из продукта (эффектно для демо), нужна кнопка в навигационном меню UI.

Это само по себе является частью демо: "презентация запускается из LeaderOS".

---

## Решение

Добавить пункт `Презентация` в навигационное меню `fragments/layout.html`.
Кнопка открывает `/presentation.html` в новой вкладке (`target="_blank"`).

---

## Изменения в файлах

### 1. Скопировать файл презентации

```bash
cp leaderOS-pitch-v5.html \
  JavaMemoryService/src/main/resources/static/presentation.html
```

Spring Boot автоматически отдаёт файлы из `static/` по пути `/filename`.
Дополнительных роутов и контроллеров не нужно.

### 2. `fragments/layout.html` — добавить пункт навигации

Найти блок навигационных ссылок (ul с классом navbar-nav или аналогичным) и добавить:

```html
<li class="nav-item">
  <a class="nav-link" href="/presentation.html" target="_blank">
    🚀 Презентация
  </a>
</li>
```

Разместить последним пунктом меню, после всех существующих ссылок.

## Как тестировать

1. Собрать JAR: `mvn package -q -DskipTests`
2. Запустить: `SPRING_PROFILES_ACTIVE=local java -jar target/memory-service.jar`
3. Открыть `http://localhost:8082/ui/today`
4. Убедиться что в навигации есть пункт "🚀 Презентация"
5. Кликнуть → должна открыться презентация в новой вкладке
6. Проверить навигацию стрелками, fullscreen по клавише F
