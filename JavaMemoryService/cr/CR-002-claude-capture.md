## Проблема / Мотивация

CR-001 реализовал capture модуль в java-memory-service.
Но агент (claude --print) не знает о новом канале — нет инструкций в CLAUDE.md.

Нужно: написать агенту "заметка после встречи с Петром: он хочет уйти" →
агент кладёт файл в `capture-inbox/` и/или вызывает `POST /api/capture`.

---

## Решение

Добавить секцию `## Capture Bot` в `CLAUDE.md`.

---

## Изменения в CLAUDE.md

Добавить после секции `## Workspace структура`:

```markdown
## Capture Bot

### Когда использовать

Если пользователь говорит одно из:
- "заметка", "запомни", "зафиксируй", "capture"
- "после встречи", "по звонку", "идея", "риск"
- любая фраза с намерением сохранить наблюдение

→ **Немедленно сохрани**, не задавай уточняющих вопросов.

### Как сохранять

**Вариант A — только файл (если memory-service недоступен):**

Создай файл `capture-inbox/YYYY-MM-DD/HH-MM-SS.md`:

```
---
date: YYYY-MM-DD HH:MM:SS
source: agent
---
<текст пользователя дословно>
```

**Вариант B — через API (предпочтительно, если сервис запущен):**

```bash
curl -s -X POST http://localhost:8082/api/capture \
  -H "Content-Type: application/json" \
  -d '{"text": "<текст>", "source": "agent"}'
```

Файл в `capture-inbox/` создай в любом случае — как резервную копию.

### Правила

- **Не классифицируй** — сохрани raw текст как есть
- **Не интерпретируй** — даже если кажется что это задача или риск
- **Не спрашивай** куда класть — это решит агент вечером
- Подтверди коротко: `✓ Записал в capture-inbox`

### Примеры

| Пользователь пишет | Агент делает |
|--------------------|--------------|
| "заметка: Иван не знает rollback" | сохраняет файл, отвечает "✓ Записал" |
| "после встречи: решили не трогать монолит до Q3" | сохраняет файл, отвечает "✓ Записал" |
| "риск: только один человек знает деплой" | сохраняет файл, отвечает "✓ Записал" |
| "запомни: Петров хочет перейти в другую команду" | сохраняет файл, отвечает "✓ Записал" |
```
