# Test Plan — CR-001: Capture Bot

**CR:** CR-001-capture-bot  
**Дата:** 2026-06-09  
**Сервис:** JavaMemoryService (порт 8082)  
**Профиль:** local (H2) или prod (PostgreSQL)

---

## Предусловия

```bash
# Запустить сервис
cd JavaMemoryService
mvn spring-boot:run -Dspring-boot.run.profiles=local

# Убедиться, что сервис поднялся
curl http://localhost:8082/actuator/health
# Ожидание: {"status":"UP"}

# Добавить CLI-алиас (если ещё не добавлен)
capture() {
  curl -s -X POST http://localhost:8082/api/capture \
    -H "Content-Type: application/json" \
    -d "{\"text\": \"$*\", \"source\": \"cli\"}" | jq -r '.captureId'
}
```

---

## T-01 — POST /api/capture: базовый захват заметки

**Цель:** заметка сохраняется в БД и файле `capture-inbox/`.

```bash
ID=$(capture "Иван не знает rollback — нужно провести сессию")
echo "captureId: $ID"
```

**Проверки:**
- [ ] Ответ содержит `captureId` (число) и `savedAt` (ISO timestamp)
- [ ] `captureId` не null и не пустой
- [ ] Файл создан: `ls capture-inbox/$(date +%Y-%m-%d)/`  
      Должен появиться файл вида `HH-mm-ss-{id}.md`
- [ ] Содержимое файла:
  ```bash
  cat capture-inbox/$(date +%Y-%m-%d)/*${ID}.md
  # Ожидание: заголовок "# Capture ...", строка "source: cli", текст заметки
  ```

## T-02 — POST /api/capture: поле source по умолчанию

**Цель:** если `source` не передан — используется `"cli"`.

```bash
curl -s -X POST http://localhost:8082/api/capture \
  -H "Content-Type: application/json" \
  -d '{"text": "заметка без source"}' | jq .
```

**Проверки:**
- [ ] Ответ содержит `captureId`
- [ ] Запись в БД имеет `source = 'cli'`

## T-03 — GET /api/capture/today

**Цель:** возвращает все captures за сегодня.

```bash
# Добавить несколько заметок
capture "Риск: только один человек знает деплой в prod"
capture "Надо разобраться как устроен service-mesh у нас"

curl -s http://localhost:8082/api/capture/today | jq length
```

**Проверки:**
- [ ] Возвращается массив (минимум те заметки, что добавили выше)
- [ ] Каждый элемент имеет поля: `id`, `rawText`, `source`, `status`, `capturedAt`
- [ ] `status` у всех = `"PENDING"`
- [ ] Заметки из прошлых дней (если есть) **не** попадают в ответ

## T-05 — POST /api/capture/process-today: обработка без PENDING

**Цель:** если нет PENDING captures — сервис не вызывает `claude`, возвращает `total: 0`.

```bash
# Сначала убедиться, что нет PENDING (или использовать чистую БД)
curl -s -X POST http://localhost:8082/api/capture/process-today | jq .
```

**Проверки (при отсутствии PENDING):**
- [ ] Ответ: `{"total": 0, "routed": 0}`
- [ ] `claude` **не** запускается (нет побочных эффектов)

## T-06 — POST /api/capture/process-today: полный цикл с claude

**Цель:** классификатор запускается, заметки маршрутизируются по типам.

```bash
# Подготовка: добавить заметки разных типов
capture "Надо сделать задачу: написать ADR по service mesh"
capture "Риск: только один человек знает деплой в prod"
capture "Как работает circuit breaker в нашем стеке?"
capture "Встреча с Петром — он хочет перейти в другую команду"
capture "Паттерн Saga используется для распределённых транзакций"
capture "День был продуктивный: закрыл 3 задачи"

# Запустить обработку
curl -s -X POST http://localhost:8082/api/capture/process-today | jq .
```

**Проверки:**
- [ ] Ответ содержит `total >= 6` и `routed > 0`
- [ ] `routed == total` (все заметки обработаны без ошибок)
- [ ] Статус captures обновился на `PROCESSED`:
  ```bash
  curl -s http://localhost:8082/api/capture/today | jq '[.[] | .status] | unique'
  # Ожидание: ["PROCESSED"]
  ```
- [ ] Поля `classified` и `routedTo` заполнены у processed captures

**Проверка маршрутизации по типам:**

| Тип | Проверка |
|-----|----------|
| `TASK` | `curl http://localhost:8082/api/tasks/pending` — задача присутствует |
| `RISK` | `curl http://localhost:8082/api/risks` — риск присутствует |
| `QUESTION` | `curl http://localhost:8082/api/questions` — вопрос присутствует |
| `PERSON_NOTE` | `curl "http://localhost:8082/api/people/name/Петр/notes"` — заметка присутствует |
| `KNOWLEDGE` | `ls ../JavaRagService/rag-inbox/captures/` — файл `.md` создан |
| `JOURNAL` | `cat ../workspace/08_daily_journal/$(date +%Y-%m-%d).md` — запись добавлена |

## Известные ограничения

- **T-06 требует запущенного `claude` CLI** в PATH. Если `claude` недоступен — `process-today` вернёт `{"total": N, "routed": 0}` с ошибкой в логах.
- Пути `app.rag.inbox-dir` и `app.workspace.dir` по умолчанию относительные (`../JavaRagService/rag-inbox`, `../workspace`). Если сервис запущен не из корня проекта — переопределить в `application-local.properties`.
- Scheduler 18:00 активен при любом профиле. Для тестов вне этого времени использовать ручной вызов `POST /api/capture/process-today`.
