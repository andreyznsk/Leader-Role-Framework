# Карточки сервисов

Одна карточка = один сервис. Создаётся автоматически arch-analyst или вручную.

## Как создать карточку

```
Используй суб-агент arch-analyst:
"Создай карточку для сервиса [название].
 Прочитай README в репозитории [ссылка]."
```

Или скопируй шаблон `_template.md` → `[service-name].md`
